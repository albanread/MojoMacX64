# Divergences from the MojoCocoa tree that are ALLOWED, with their reason.
#
# One line per entry: <path>|<symbol-or-WHOLEFILE>|<sha256-16 of OUR version>|<reason>
#
# The hash makes the allowlist a TWO-SIDED contract: the symbol may differ from
# upstream, and it may not change here without someone deliberately updating
# this file. Without it an allowlisted symbol is an unguarded hole -- which is
# exactly where our most ABI-critical code lives.
#
# Nothing lands here without evidence -- clang's own output, the cocoa.sqlite
# tables, or a measurement on this hardware. An entry is a promise that the
# difference is required by x86-64, not that it was convenient. See
# PARITY_SPRINT.md.
